Computer Vision Gait Analysis
Overview
This project implements an AI-powered gait analysis system using computer vision and pose estimation techniques.

The system processes walking videos, extracts human body keypoints, generates gait metrics, and visualizes movement patterns for healthcare and rehabilitation applications.

Features
Human pose estimation
Walking pattern analysis
Gait metric extraction
Video processing
